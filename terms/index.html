3. How the Service works

3.1 Servers. To connect a server, you run a command from the Service on it. The installer creates a tterm user with no password and passwordless sudo, and adds the Service's certificate authority (CA) to its authorized_keys. The Service signs in to the server over SSH with a certificate that is valid for 2 minutes and contains your name; every sign-in is visible in the server's log (auth.log). The installer does not change the server's SSH settings.

3.2 Computers. To connect a computer, you install the Agent in the ~/.tterm-web folder. The Agent starts when you log in to the computer and runs as your user, without root rights. It keeps the connection to the Service itself and starts a shell when you open a Terminal.

3.3 Terminals. A Terminal runs on the Service's server, not in your browser: closing the tab does not stop it. Each command is saved as a block: its text, directory, time, exit code and output. What is kept and for how long is described in the Policy.

3.4 Access to Machines. By connecting a Machine, you give the Service the access described above. You can remove it yourself: with the Remove machine button and the command the Service shows you for a server, or with ~/.tterm-web/uninstall.sh on a computer.
