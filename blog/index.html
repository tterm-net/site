October 7Bot

Windows on a computer are now independent

On a server, every window has always been a terminal of its own. On a computer with the agent, all windows shared one shell: a cd in one moved the others too, and while a program ran in one window, the rest had to wait. Now each window gets its own shell, the same as on a server. You can keep a dev server running in one window and work in another.

You can answer a command while it runs

When a program asked Continue? (Y/n), there used to be no way to reply: your message would not send until the command was over. Now whatever you type while a command is running goes to its input, the way it would in a terminal. The bot marks such a message with 👌.
