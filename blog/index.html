October 2026

October 7Bot

Independent windows on a computer

Terminal windows on a computer with the agent are now independent: each one has its own shell, as on a server, and cd in one no longer moves the others. To get this, update the agent by running the install again from /addhost → Computer. The window buttons now sit at the bottom of the list and stay put when you switch. A computer no longer shows as offline after the agent reconnects quickly.

September 2026

September 30Bot

Answer a command as it runs

You can now answer a command while it runs: whatever you type goes to its input, the way it would in a terminal. Yes/no questions are recognised even with a spinner turning below them. A computer with the agent no longer drops out of the list after half an hour without commands.

September 17Bot

Your own shell

The agent now runs your own shell, bash or zsh, so the environment and the paths are the ones you see in a normal terminal. Commands that leave nothing to fix ask for confirmation. The server's key is checked on every connection. Long output arrives with a summary instead of its last few lines.

September 1Bot

Several terminals on one machine

A machine can now hold several terminals, the way you keep more than one window open on a server. Output appears as it arrives, with a Stop button, and a command waiting for an answer says so instead of hanging silently. The git branch sits above the prompt, and longer output stays in the chat instead of turning into a file.

August 2026

August 30Site

The site and the channel

tterm.net is live, along with the channel where changes get announced. The bot and the agent are open source.

August 28Bot

The bot on its own server

The bot moved to its own server and no longer depends on a laptop being open. Source for the bot and the agent is public.

August 26Bot

Buttons in messages

Machine list, menus and confirmations moved to buttons inside messages. A machine that cannot be reached is greyed out instead of leading to an error.

August 25Bot

Access with a time limit

Shared access with time limits. Expired access closes itself and both sides are told. Owners can export the full command history as a file.

August 23Bot

Computers through an agent

Computers can be connected too, through a small agent that dials out. macOS and Linux for now.
