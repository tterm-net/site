tTerm is live

A terminal for your servers, right here in Telegram. Type a command – it runs on your machine, and the reply comes back as a message with the exit code, the working directory and the git branch. The shell remembers where you left off.

What works today

  • Linux servers over SSH – one command to connect, no sshd_config edits
  • macOS and Linux computers through a small agent that opens no ports
  • Give access to any Telegram user – for a set time or until you take it back
  • Every command they run lands in your log with their name on it

Free, open source, no signup.

It is beta. It works, and it will keep changing, this channel is where the changes get announced.

From our Telegram channel @tTermBlog.
