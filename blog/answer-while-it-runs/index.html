You can answer a command while it runs

When a program asked Continue? (Y/n), there used to be no way to reply: your message would not send until the command was over. Now whatever you type while a command is running goes to its input, the way it would in a terminal. The bot marks such a message with 👌.

What else changed

  • (Y/n) questions are recognised even with a spinner turning below them, the way wrangler or npm ask. Buttons for y and n appear
  • The Stop button now sits right under the command's output and interrupts it with Ctrl+C
  • A computer with the agent no longer drops out of the list after half an hour without commands
