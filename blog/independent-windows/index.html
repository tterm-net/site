Windows on a computer are now independent

On a server, every window has always been a terminal of its own. On a computer with the agent, all windows shared one shell: a cd in one moved the others too, and while a program ran in one window, the rest had to wait. Now each window gets its own shell, the same as on a server. You can keep a dev server running in one window and work in another.

To get this, update the agent: /addhost → Computer, then run the command it gives you on the same computer. The machine stays in your list as it is. If your agent is an old one, the bot will tell you when you open a second window.

What else changed

  • Window buttons sit at the bottom of the list and apply to the selected line, so they no longer jump around when you switch
  • If you switch to a window where a command is running, the bot says so right away instead of waiting for it to finish
  • A computer no longer shows as offline after the agent quickly reconnects
