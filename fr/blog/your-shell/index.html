L’agent lance désormais votre shell : bash ou zsh

Auparavant, l’agent lançait bash quoi qu’il arrive. Sur macOS, où zsh est le shell par défaut depuis 2019, cela voulait dire un environnement qui n’était pas le vôtre : la moitié de ce que vous aviez installé restait introuvable.

Désormais, c’est le shell que vous utilisez vous-même, avec vos chemins et vos réglages, comme quand vous ouvrez Terminal.

Autres changements

  • Une commande après laquelle il n’y a plus rien à réparer demande d’abord confirmation : rm -rf, mkfs, DROP DATABASE, l’arrêt de sshd
  • La clé d’hôte du serveur est enregistrée quand vous le connectez, puis vérifiée à chaque connexion, si bien qu’une autre machine qui répondrait à cette adresse ne passerait pas
  • Une longue sortie arrive avec un résumé au lieu de ses six dernières lignes : pour apt, vous voyez désormais combien de paquets ont été mis à jour, et pas seulement Processing triggers
  • Les chemins longs sont raccourcis dans l’invite : /opt/…/tterm/core
