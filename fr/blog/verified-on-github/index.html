tTerm est désormais une organisation vérifiée sur GitHub

github.com/tterm-net porte le badge Verified : GitHub a confirmé que derrière l’organisation et tterm.net se trouvent les mêmes personnes.

C’est plus important ici qu’ailleurs. Le code est ouvert, donc n’importe qui peut le forker, modifier la commande d’installation et le publier sous un nom qui ressemble au nôtre. Un domaine, lui, ne se forke pas. Le badge relie les deux, et il existe ainsi un endroit dont on peut prouver que c’est bien nous :

  • github.com/tterm-net : les trois dépôts, vérifiés
  • tterm.net : le site
  • @tTermNetBot : le bot lui-même
