Sur un ordinateur, les fenêtres sont désormais indépendantes

Sur un serveur, chaque fenêtre a toujours été un terminal à part entière. Sur un ordinateur équipé de l’agent, toutes les fenêtres partageaient un seul shell : un cd dans l’une déplaçait aussi les autres, et tant qu’un programme tournait dans une fenêtre, les autres devaient attendre. Désormais, chaque fenêtre a son propre shell, comme sur un serveur. Vous pouvez laisser tourner un serveur de développement dans une fenêtre et travailler dans une autre.

Pour en profiter, mettez à jour l’agent : /addhost → Computer, puis lancez la commande obtenue sur le même ordinateur. La machine reste telle quelle dans votre liste. Si votre agent est ancien, le bot vous le signalera quand vous ouvrirez une deuxième fenêtre.

Autres changements

  • Les boutons des fenêtres se trouvent en bas de la liste et s’appliquent à la ligne sélectionnée, ils ne se déplacent donc plus quand vous changez de fenêtre
  • Si vous passez à une fenêtre où une commande s’exécute, le bot vous le dit tout de suite au lieu d’attendre qu’elle se termine
  • Un ordinateur n’apparaît plus offline après une reconnexion rapide de l’agent
