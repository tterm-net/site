tTerm pour Mac : un terminal local avec le cloud intégré

tTerm a désormais une application pour Mac. Elle ouvre les shells de votre ordinateur sous forme de blocs et fonctionne sans compte. Une fois connecté, vous retrouvez vos serveurs du cloud dans la même fenêtre. Gratuit, macOS 11 ou version ultérieure.

Pourquoi une application en plus

tTerm Web, c’est le terminal dans le cloud : les terminaux de vos serveurs tournent dans le cloud et s’ouvrent depuis n’importe quel navigateur. Mais le travail commence souvent sur votre propre ordinateur : compilations, git, docker. Pour cela, il fallait un terminal à part, avec tTerm ouvert à côté dans un onglet du navigateur. Désormais, votre Mac et le cloud sont réunis dans une seule fenêtre.

Ce que fait l’application

  • Des blocs sur votre propre Mac. Le bash ou le zsh de ce Mac, chaque commande dans un bloc avec sa sortie, son code de retour et sa durée. Une ligne de saisie avec historique et Tab, et tTerm demande confirmation avant une commande dangereuse. L’historique reste 30 jours sur le Mac.
  • Aucun compte nécessaire. Les terminaux, l’historique et les notes de ce Mac sont conservés sur le Mac lui-même. Un compte n’est nécessaire que pour le cloud.
  • Le cloud dans la même fenêtre. Connectez-vous via votre navigateur, et vos serveurs, leurs notes et la recherche globale avec ⌘K s’ouvrent à côté des terminaux du Mac.
  • Votre Mac, où que vous soyez. L’application ouvre ce Mac à tTerm Web : son terminal est accessible depuis un navigateur et depuis votre téléphone. tTerm se loge dans la barre des menus et démarre avec votre Mac.
  • Mises à jour automatiques. Toutes les six heures, tTerm vérifie s’il existe une nouvelle version et l’installe quand cela ne gêne pas. Si vous préférez décider vous-même, demandez-lui dans Settings → Updates de vous consulter d’abord.

Comment l’installer

Téléchargez tTerm sur la page de téléchargement, ouvrez tTerm.dmg et faites glisser tTerm dans le dossier Applications. L’application est signée avec notre propre certificat, et non avec un Apple Developer ID, donc la première fois, macOS vous demande de confirmer l’ouverture. La page de téléchargement montre comment faire. Ensuite, tTerm s’ouvre normalement, et macOS ne vous pose aucune question sur les mises à jour.

La suite

Bientôt, l’application trouvera les serveurs et les clés dans ~/.ssh sur ce Mac et les transférera vers le cloud en quelques clics. Ensuite viendront Windows et Linux. Le code de l’application est ouvert, comme tout tTerm : github.com/tterm-net/tterm-app, AGPL v3.
