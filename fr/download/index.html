Le lien avec le cloud

Commencez sur votre Mac,
passez au cloud

L’application ne remplace pas tTerm dans le cloud, elle le complète : un seul compte, les mêmes serveurs et les mêmes notes. Commencez sur votre propre Mac, et quand vous aurez besoin d’un accès de partout, transférez tout vers le cloud.

Nouveau

tTerm pour Mac

Un terminal local sur votre Mac : les shells de cet ordinateur sous forme de blocs, avec l’historique et les notes conservés sur place. Il fonctionne aussi sans compte.

BIENTÔT

Passer au cloud

Quand vous êtes prêt, l’application retrouve sur le Mac vos serveurs et vos clés dans ~/.ssh et les transfère vers le cloud en quelques clics.

tTerm Web

Le terminal dans le cloud : serveurs, terminaux et notes sont hébergés dans le cloud et s’ouvrent depuis n’importe quel navigateur, depuis votre téléphone et pour votre équipe.

Fonctionnalités

Votre Mac et le cloud dans une seule fenêtre

Des blocs sur votre Mac aussi

Le bash ou le zsh de ce Mac, chaque commande dans un bloc avec sa sortie, son code de retour et sa durée. L’historique reste 30 jours sur le Mac.

Le cloud dans la même fenêtre

Une fois connecté, vous retrouvez vos serveurs, leurs notes et la recherche globale avec ⌘K à côté des terminaux du Mac.

Passer au cloud BIENTÔT

L’application transfère les serveurs et les clés de ce Mac vers le cloud en quelques clics, et ils s’ouvrent ensuite depuis n’importe quel navigateur.

Votre Mac, où que vous soyez

L’application ouvre ce Mac à tTerm Web : son terminal est accessible depuis un navigateur et depuis votre téléphone. Elle se loge dans la barre des menus.

Installation

Votre Mac dans tTerm en trois étapes

01

Ouvrez le fichier

Ouvrez le fichier tTerm.dmg téléchargé et faites glisser tTerm dans le dossier Applications.

02

Lancez tTerm

La première fois, macOS vous demande de confirmer l’ouverture, voici comment faire. Ensuite, les terminaux de ce Mac fonctionnent tout de suite, sans compte ni configuration.

03

Connectez-vous quand vous voulez

Le bouton Sign in ouvre votre navigateur : confirmez la connexion, et vos serveurs et vos notes apparaissent dans la fenêtre.

Le premier lancement, une seule fois

macOS 15 ou version ultérieure
Ouvrez tTerm et cliquez sur « OK ». Allez ensuite dans « Réglages Système » → « Confidentialité et sécurité » : en bas, à côté de la ligne concernant tTerm, cliquez sur « Ouvrir quand même » (le bouton reste affiché environ une heure après votre tentative) et confirmez avec le mot de passe de votre Mac.
macOS 11–14
Dans le Finder, ouvrez le dossier Applications, cliquez sur tTerm en maintenant la touche Contrôle enfoncée, choisissez « Ouvrir », puis cliquez de nouveau sur « Ouvrir ».

Ensuite, tTerm s’ouvre normalement et installe lui-même les nouvelles versions, et macOS ne vous pose aucune question à leur sujet.

Questions

Quelle différence avec tTerm Web ?

tTerm Web est un terminal dans le cloud, dans votre navigateur : les terminaux de vos serveurs et ordinateurs tournent dans le cloud, et vous les ouvrez de n’importe où. tTerm pour Mac est un terminal local, sur le Mac lui-même, avec tout le cloud dans sa fenêtre. Un seul compte, les mêmes serveurs et les mêmes notes.

Est-ce gratuit ?

Oui. Tant que tTerm est en bêta, il est gratuit pour tout le monde, l’application aussi.

Faut-il un compte ?

Non. Sans connexion, tTerm fonctionne avec ce Mac : shells, historique et notes y restent. Le compte sert au cloud : les serveurs, les notes sur tous vos appareils et ce Mac depuis un navigateur.

Où sont conservées mes commandes ?

Les commandes de ce Mac et leur sortie y restent 30 jours, dans le dossier de l’application, que vous seul pouvez lire. Les commandes exécutées sur les serveurs sont conservées dans le cloud, comme dans tTerm Web.

L’application est-elle signée ?

Oui, avec le propre certificat de tTerm, qui sert aussi à signer chaque mise à jour. Il n’y a pas encore de signature Apple Developer ID, donc la première fois, macOS vous demande de confirmer l’ouverture, voici comment faire. Ensuite, il ne le redemande plus, mises à jour comprises.

Comment tTerm se met-il à jour ?

Tout seul. Toutes les six heures, tTerm vérifie s’il existe une nouvelle version, la télécharge et l’installe quand cela ne gêne pas : quand vous quittez l’application ou quand rien ne tourne dans ses terminaux. Dans Settings → Updates, vous pouvez lui demander de vous consulter d’abord.

Comment désinstaller tTerm ?

Quittez tTerm depuis la barre des menus, puis faites-le glisser du dossier Applications vers la Corbeille. Si vous vous étiez connecté, vous pouvez oublier ce Mac dans Settings → Devices.

Le code est-il ouvert ?

Oui, sous AGPL v3, comme tout tTerm : github.com/tterm-net/tterm-app.

Votre première commande sur Mac en une minute

Téléchargez tTerm, faites-le glisser dans Applications et lancez-le. Aucun compte nécessaire.
