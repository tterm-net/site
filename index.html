Three steps to start

  1. Open the bot

    No account, no signup. The chat is the interface.

  2. Run one command on your server

    The bot hands you a one-liner. It creates a separate user and trusts our certificates — nothing else is touched.

  3. Confirm it in the chat

    The server shows up, and you can start typing commands at it.

Secure access to your servers

A one-time certificate

Every connection gets a fresh certificate that expires in 15 minutes. Your SSH keys never leave your machine, because we never ask for them.

Your SSH config is not touched

Trust is added to one user's authorized_keys. We never edit sshd_config and never restart the daemon.

Quick removal

One command removes the user and the sudo rule. Nothing is left behind.

The source is fully open

The bot and the agent are open source. So is the install script — read it before you run it, it is short.

Share access with one command

Give access to any Telegram user with one command. They work in their own chat, and every command they run shows up in your log with their name on it. 

/share #12 @john 4h   give access for four hours
/revoke #12 @john     take it back, cutting the live session
