Security

We keep no keys.
We open no ports.

Access to your machines is easy to give and just as easy to take back. This is how it works.

A two-minute certificate

Every connection gets its own SSH certificate with your name in it, good for that one server only. We never need your keys.

Signing kept apart

The CA keys live in a separate process with no network. The core cannot read them, only ask for a signature, and every signature is logged.

sshd_config untouched

Trust is one line in one user's authorized_keys. Nothing gets restarted.

Connections from the inside

The agent on a computer dials out by itself, so no inbound ports are needed. It uninstalls with one command.

No middlemen

The page and the terminals go straight to our server in the EU. Cloudflare is only our DNS and never sees your commands.

Open source

tTerm Web and the agent are open source under the AGPL. The install script is short: read it before you run it.

Questions

Do I need to install anything on my computer?

No, a browser is enough. You install something only on the machines you connect to: one command on a server, a small agent on a computer.

What do you store?

Commands and their output for 30 days, to show your history, and a log of sign-ins. We keep no keys and no passwords. The details are in the Privacy Policy.

How is this better than a regular SSH client?

It works from any browser and needs no keys on your device. The terminal does not drop when you close your laptop. And every command comes as a block that is easy to copy and run again.

How do I take access away from tTerm?

Remove the server in tTerm, and it takes its own access off the server. If the server does not answer, tTerm shows the command that does it there. How to remove everything else the installer set up is written at the top of the script itself. The agent leaves a computer with one command.

What about the Telegram bot?

It stays and keeps working: a terminal right in the chat, @tTermNetBot. For now the web app and the bot live separately.

How do I contact support?

Write to support@tterm.net. If you have found a vulnerability, write to security@tterm.net.
