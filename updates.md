# Updates for tterm.net
#
# One entry per release worth telling about — not per version. The site
# builds both language lists from here, so the two cannot drift apart.
#
# Newest first. Dates in ISO form; the pages format them per language.

## 2026-09-01

@en
A machine can now hold several terminals, the way you keep more than one window open on a server. Output appears as it arrives, with a Stop button, and a command waiting for an answer says so instead of hanging silently. The git branch sits above the prompt, and longer output stays in the chat instead of turning into a file.

@ru
На одной машине теперь можно держать несколько терминалов — как несколько окон на сервере. Вывод появляется по мере готовности, с кнопкой Stop, а команда, которая ждёт ответа, говорит об этом, а не висит молча. Ветка git встала над приглашением, и длинный вывод остаётся в чате, а не уходит файлом.

## 2026-08-30

@en
tterm.net is live, along with the channel where changes get announced. The bot and the agent are open source.

@ru
Заработал сайт tterm.net и канал, где мы рассказываем об изменениях. Исходники бота и агента открыты.

## 2026-08-28

@en
The bot moved to its own server and no longer depends on a laptop being open. Source for the bot and the agent is public.

@ru
Бот переехал на свой сервер и больше не зависит от того, открыт ли ноутбук. Исходники бота и агента открыты.

## 2026-08-26

@en
Machine list, menus and confirmations moved to buttons inside messages. A machine that cannot be reached is greyed out instead of leading to an error.

@ru
Список машин, меню и подтверждения переехали на кнопки внутри сообщений. Машина не на связи теперь серая, а не ведёт в ошибку.

## 2026-08-25

@en
Shared access with time limits. Expired access closes itself and both sides are told. Owners can export the full command history as a file.

@ru
Доступ для других со сроком. Истёкший закрывается сам, и обоим приходит уведомление. Всю историю команд можно выгрузить файлом.

## 2026-08-23

@en
Computers can be connected too, through a small agent that dials out. macOS and Linux for now.

@ru
Подключаются и компьютеры — через маленький агент, который сам держит связь. Пока macOS и Linux.
