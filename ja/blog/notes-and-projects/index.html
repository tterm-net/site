ノート、色分けされたプロジェクト、ターミナルの名前

手順書、チェックリスト、アクセス情報などのノートを、対象のマシンのすぐそばに置けるようになりました。プロジェクトを自分で作って色を付けたり、ターミナルに名前を付けたり、マシンやノートを別のプロジェクトへ移したりもできます。公開から最初の数日で tTerm Web に加わった機能を紹介します。

マシンのすぐそばにノート

ターミナルがプロジェクトのマシン上にあるのと同じように、ノートはプロジェクトのフォルダーにあります。デプロイの手順書、リリースのチェックリスト、アクセス用の鍵の保管場所といったものです。ノートはターミナルの隣にタブとして開くので、手順書を見ながら作業を進められます。

入力と同時に Markdown を反映

行頭の # で見出し、- [ ] でチェックリストの項目、バッククォート 3 つでコードブロックになり、/ でこれらをまとめたメニューが開きます。コードには Copy ボタンが付きます。チェックリストでは誰がいつ項目にチェックを入れたかがわかり、ノート全体を Markdown としてコピーできます。

2 台のデバイスから同時に編集

ノートは入力するそばから保存されます。2 台のデバイスで同時に編集しても両方の変更が残り、tTerm が確認するのは、両側で同じ箇所が変更されたときだけです。接続が切れても、入力した内容はブラウザーに残り、次にノートを開いたときに戻ってきます。

プロジェクトを自由に作成

Personal のほかに、プロジェクトを自分で作れるようになりました。クライアントごと、環境ごと、仕事ごとに作れ、それぞれが専用のマシン、ターミナル、ノートを持ちます。どのプロジェクトも名前を変更でき（Personal も含みます）、タブに付くコード（CX/web-01 の CX など）も変えられます。マシンのないプロジェクトは、ノートごと削除できます。

マシンは、ターミナルを動かしたまま別のプロジェクトへ移せます。マシン自体には何も変更が加わりません。ノートも、別のプロジェクトの好きなフォルダーへ移せます。

プロジェクトを色分け

各プロジェクトには 8 色のうち 1 色が割り当てられます。サイドバーとタブのプロジェクトコードがその色で塗られるので、どのプロジェクトのタブかがひと目でわかります。アカウントページでは、色をコードだけに付けるか、サイドバーのプロジェクトのブロック全体に付けるかを選べます。

ターミナルの名前

ターミナルを terminal 2 のままにしておく必要はもうありません。deploy、logs、migrations のように名前を付けられます。タブ、サイドバー、プロジェクトのページのいずれかでターミナルをダブルクリックし、名前を入力して Enter を押します。名前は、そのターミナルが表示されるすべての場所に表示されます。

新しいサイドバーとプロジェクトごとのページ

サイドバーには、プロジェクトごとにマシンとそのターミナル、フォルダーに分けたノートが並びます。マシンやフォルダーをクリックすると折りたたまれるだけで、横の＋ボタンでターミナルを開いたりノートを作成したりします。プロジェクト名をクリックするとそのページが開き、すべてのマシンと開いているターミナル、すべてのノートが表示されます。

今後の予定

次に取り組む大きなテーマは、チームでの作業です。プロジェクトへのメンバーの参加、役割、コマンドの共有ログ、同僚のターミナルのライブ閲覧を予定しています。閲覧されている側には、誰が見ているかが常に表示されます。そのときには、ノートもプロジェクトの全員で共有されるようになります。

並行して、コンピューター用の tTerm も開発しています。同じインターフェースを専用のウィンドウで使い、お使いのコンピューターのシェルを操作できるものです。

tTerm Web を試す

メールアドレスでサインインします。コードが届き、それ以降は自分のデバイスなら短いコードだけで済みます。最初のサーバーは 1 分で接続できます。
