Mac 版 tTerm：クラウドを内蔵したローカルターミナル

tTerm に Mac 版アプリが加わりました。お使いの Mac のシェルをブロックで開き、アカウントがなくても使えます。サインインすると、同じウィンドウにクラウドのサーバーも表示されます。無料、macOS 11 以降に対応。

なぜアプリも作ったのか

tTerm Web はクラウドターミナルです。サーバーのターミナルはクラウドにあり、どのブラウザーからでも開けます。でも、ビルドや git、docker など、作業は自分のコンピューターで始まることがよくあります。そのためには別のターミナルが必要で、tTerm はその隣のブラウザーのタブで開いていました。これからは、Mac とクラウドを 1 つのウィンドウで使えます。

できること

  • 自分の Mac でもブロック。 この Mac の bash や zsh で、コマンドがそれぞれ出力、終了コード、時間とともにブロックになります。入力行では履歴と Tab 補完が使え、危険なコマンドの前には tTerm がもう一度確認します。履歴は 30 日間、Mac に保存されます。
  • アカウントは不要。 この Mac のターミナル、履歴、ノートは、Mac 自体に保存されます。アカウントが必要なのは、クラウドを使うときだけです。
  • 同じウィンドウにクラウドも。 ブラウザーからサインインすると、Mac のターミナルの隣に、サーバーとそのノート、⌘K による全体検索が開きます。
  • どこからでも自分の Mac に。 アプリがこの Mac を tTerm Web につなぎ、ブラウザーやスマートフォンからこの Mac のターミナルを使えるようにします。tTerm はメニューバーに常駐し、Mac と一緒に起動します。
  • 自動でアップデート。 tTerm は 6 時間ごとに新しいバージョンがないか確認し、作業の妨げにならないときにインストールします。自分で決めたい場合は、Settings → Updates で、先に確認するよう設定できます。

インストール方法

ダウンロードページから tTerm をダウンロードし、tTerm.dmg を開いて、tTerm を「アプリケーション」フォルダーにドラッグします。アプリは Apple Developer ID ではなく、tTerm 独自の証明書で署名しているため、初回は macOS から起動の確認を求められます。手順はダウンロードページで説明しています。その後は tTerm が通常どおり開き、アップデートについて macOS から確認を求められることもありません。

今後の予定

まもなく、この Mac の ~/.ssh にあるサーバーと鍵をアプリが見つけて、数クリックでクラウドへ移せるようになります。その後は Windows と Linux にも対応する予定です。アプリのコードも、tTerm 全体と同じく AGPL v3 で公開しています：github.com/tterm-net/tterm-app。
