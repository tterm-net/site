Mac 版 tTerm2026年11月4日·3 分で読めます

クラウドへ移行：Mac のサーバーと鍵を、どのブラウザーからでも開けるようになりました

Mac 版 tTerm で、Mac から ssh で接続しているサーバーを、SSH 鍵と一緒にクラウドへ移せるようになりました。鍵は Mac の中で暗号化されて保管庫に入り、開けるのはあなただけです。どのブラウザーでも、保管庫のパスワードで開けます。

なぜクラウドへ移すのか

Mac からサーバーへは ssh で接続します。鍵は ~/.ssh に、アドレスとユーザーは ~/.ssh/config にあります。でも Mac から離れると、ブラウザーからも、スマートフォンからも、ほかの人のコンピューターからも、そのサーバーには届きません。「クラウドへ移行」でサーバーを tTerm に移せば、どこからでも開けるようになります。

どこにあるか

Mac 版 tTerm で、サイドバーの下にあるアカウントをクリックし、「クラウドへ移行」を選びます。ウィンドウには「この Mac のサーバー」が表示されます。これらは、~/.ssh/config、known_hosts、そして tTerm のターミナルで実行した ssh コマンドから tTerm が集めたものです。「移行」を押すまで、何もどこにも送られません。

3 つのログイン方法

サーバーごとに、それぞれのログイン方法があります：

  • 「自分の鍵」： 鍵は保管庫に入り、サーバーはそのままです。
  • 「tTerm のアクセス権」： tTerm がサーバーに専用の行を追加し、鍵は Mac に残ります。
  • 「この Mac 経由」： 何も移しません。Mac が起動しているあいだ、tTerm が Mac に接続を依頼します。VPN の内側にあるサーバー向けの方法です。

適切な方法は tTerm が自動で選びますが、自分で変えることもできます。

鍵の保管庫

鍵は、Mac を離れる前に、Mac の中で暗号化されます。tTerm が持つのは、暗号文と、鍵の公開鍵部分、そのフィンガープリントだけです。私たちには、保管庫を開くことも、鍵を読むこともできません。サーバーを開くときは、あなたのデバイスがログインに署名し、鍵が暗号化されないままデバイスの外へ出ることはありません。

保管庫のパスワード

パスワードは、保管庫を作成するときに自分で決めます。このパスワードがあれば、ほかの人のコンピューターでも、Mac がなくても、どのブラウザーでも鍵を開けます。パスワード自体はどこにも送られません。tTerm はパスワードを知らず、復元することもできないので、パスワードマネージャーに保存しておいてください。自分のコンピューターでは「Touch ID で保存」を押せば、そこでは二度とパスワードを聞かれません。ほかの人のコンピューターでは「今回のみ」を選んでください。

鍵を開いた場所でのみ

あなたの鍵で開くサーバー、Mac 経由のサーバー、そして Mac 自体は、あなた自身が鍵を開いたデバイスでしか開きません。これらを開くには、メールのコードでアカウントにサインインするだけでは足りません。誰かにメールに入られたときに備えた、2 つ目のロックです。鍵が開いていない場所では、こうしたマシンに「+」の代わりにロックのアイコンが表示されます。それを押してパスワードを入力すると、ターミナルが開きます。

ssh のあとのバー

Mac 版 tTerm のターミナルで ssh がエラーなく終了すると、そのブロックの下に「鍵を保存」と「tTerm を許可」のあるバーが表示されることがあります。これを使えば、移行のウィンドウを開かずに、サーバーを 1 台だけ移せます。

これらはすべて Mac 版 tTerm 0.8.1 で使えます。詳しくは、ドキュメントの「クラウドへ移行」と「SSH 鍵の保管庫」のページをご覧ください。
