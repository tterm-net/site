tTerm Web2026年11月4日·2 分で読めます

サポート：tTerm から直接お問い合わせください

アカウントメニューに「ヘルプ」が加わり、ドキュメントを開いたり、tTerm から直接サポートにメッセージを送ったりできるようになりました。返信はメールで届きます。メッセージに添えられる技術情報は送信前に確認でき、添付しないこともできます。

なぜ作ったのか

tTerm についての質問は、たいてい作業の途中で出てきます。マシンがつながらない、ログが開かない、何かが思ったとおりに動かない、といったときです。これまでは、tTerm の中から問い合わせることはできませんでした。どこに連絡すればよいかを探し、使っているバージョンやブラウザーを思い出す必要がありました。今は tTerm の中でそのままメッセージを書けて、バージョンとブラウザーは tTerm が自動で添えてくれます。

どこにあるか

サイドバーの下にあるアカウントメニューは、「設定」、「言語」、「ヘルプ」、「tTerm について」の 4 つになりました。「ヘルプ」には項目が 2 つあります。「ドキュメント」を押すと、docs.tterm.net が tTerm と同じ言語で開きます。「サポートに問い合わせる」を押すと、tTerm へのメッセージを書くウィンドウが開きます。

問い合わせの方法

「何が起きたか」の欄に、起きたことを自分の言葉で書いて、「送信」または ⌘Enter（Windows と Linux では Ctrl+Enter）を押します。返信先がアカウントのメールアドレスであることは、ウィンドウに最初から表示されています。メッセージの控えもすぐにそこへ届くので、送った内容は手元にも残ります。

メッセージと一緒に送られるもの

こちらから聞き直さなくて済むように、メッセージには技術情報が 1 行添えられます。内容は tTerm Web のバージョン、ブラウザーとそれが動くシステム、プラン、マシンの台数で、たとえば「tTerm Web 0.1.25 · Chrome 141, macOS · Free プラン · マシン 3 台」のようになります。「技術情報を添付する」の下には、この行が送られるとおりの形で表示されます。コマンドやその出力、ノートが送られることはありません。この行も添付したくない場合は、チェックを外してください。メッセージだけが送られます。

送信したあと

メッセージが送られると、ウィンドウに「送信しました」と表示され、返信がどこに届くかをあらためて知らせてくれます。送れなかったときもウィンドウにそう表示され、自分でメールを送るための宛先が示されます。

tTerm について

その隣には「tTerm について」も加わりました。ここからは、tterm.net サイト、お知らせを発信している tTerm の Telegram チャンネル、そしてドキュメントの「最新情報」を開けます。「最新情報」には、tTerm Web のバージョンごとの変更点が載っています。

Mac 版 tTerm には、次のアップデートで新しいメニューと「サポートに問い合わせる」が加わります。詳しくは、ドキュメントの「ヘルプ」ページをご覧ください。
