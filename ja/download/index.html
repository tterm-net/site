クラウドとの関係

Mac で始めて、
クラウドへ移行

アプリはクラウドの tTerm に代わるものではなく、それを補うものです。アカウントは 1 つで、サーバーもノートも共通です。まずは自分の Mac で始め、どこからでもアクセスしたくなったら、すべてをクラウドへ移せます。

Mac 版 tTerm

Mac で動くローカルターミナル：このコンピューターのシェルをブロックで表示し、履歴とノートもこの Mac に保存します。アカウントがなくても使えます。

クラウドへの移行

準備ができたら、アプリが Mac の ~/.ssh からサーバーと鍵を見つけ、数クリックでクラウドへ移します。

tTerm Web

クラウドターミナル：サーバー、ターミナル、ノートはクラウドにあり、どのブラウザーからでも、スマートフォンからでも開け、チームでも使えます。

できること

Mac とクラウドを 1 つのウィンドウに

自分の Mac でもブロック

この Mac の bash や zsh で、コマンドがそれぞれ出力、終了コード、時間とともにブロックになります。履歴は 30 日間、Mac に保存されます。

同じウィンドウにクラウドも

サインインすると、Mac のターミナルの隣に、サーバーとそのノート、⌘K による全体検索が開きます。

クラウドへの移行 近日公開

この Mac にあるサーバーと鍵を、アプリが数クリックでクラウドへ移します。移したあとは、どのブラウザーからでも開けます。

どこからでも自分の Mac に

アプリがこの Mac を tTerm Web につなぎ、ブラウザーやスマートフォンからこの Mac のターミナルを使えるようにします。アプリはメニューバーに常駐します。

インストール方法

3 ステップで Mac を tTerm に

01

ファイルを開く

ダウンロードした tTerm.dmg を開き、tTerm を「アプリケーション」フォルダーにドラッグします。

02

tTerm を起動

初回は macOS から起動の確認を求められます。手順はこちら。その後は、この Mac のターミナルがすぐに使えます。アカウントも設定も必要ありません。

03

好きなときにサインイン

Sign in を押すとブラウザーが開きます。そこで確認すると、ウィンドウにサーバーとノートが表示されます。

初回の起動（1 回だけ）

macOS 15 以降
tTerm を開いて「完了」をクリックします。次に「システム設定」→「プライバシーとセキュリティ」を開き、下のほうにある tTerm についての行の横で「このまま開く」をクリックし（このボタンは、開こうとしてから約 1 時間表示されます）、Mac のパスワードを入力して確定します。
macOS 11–14
Finder で「アプリケーション」フォルダーを開き、Control キーを押しながら tTerm をクリックして「開く」を選び、もう一度「開く」をクリックします。

その後は tTerm が通常どおり開き、新しいバージョンも自動でインストールされます。macOS から確認を求められることもありません。

よくある質問

tTerm Web とは何が違いますか？

tTerm Web は、ブラウザーで使うクラウドターミナルです。サーバーやコンピューターのターミナルはクラウドにあり、どこからでも開けます。Mac 版 tTerm は Mac そのもので動くローカルターミナルで、そのウィンドウの中でクラウドのすべてを使えます。アカウントは 1 つで、サーバーもノートも共通です。

無料ですか？

はい。tTerm がベータ版のあいだは、アプリも含めてどなたでも無料です。

アカウントは必要ですか？

いいえ。サインインしなくても、tTerm はこの Mac で使えます。シェル、履歴、ノートはこの Mac に残ります。アカウントはクラウドを使うためのもので、サーバー、すべてのデバイスで使えるノート、ブラウザーからのこの Mac へのアクセスに必要です。

コマンドはどこに保存されますか？

この Mac で実行したコマンドと出力は、あなただけが読めるアプリのフォルダーに 30 日間保存されます。サーバー上のコマンドは、tTerm Web と同じくクラウドに保存されます。

アプリは署名されていますか？

はい。tTerm 独自の証明書で署名しており、アップデートもすべて同じ証明書で署名しています。Apple Developer ID による署名はまだないため、初回は macOS から起動の確認を求められます。手順はこちら。その後は、アップデートのときも含めて確認を求められることはありません。

どのようにアップデートされますか？

自動で行われます。tTerm は 6 時間ごとに新しいバージョンがないか確認してダウンロードし、作業の妨げにならないとき、つまり終了するときや、tTerm のターミナルで何も実行されていないときにインストールします。Settings → Updates で、インストールの前に確認するよう設定することもできます。

削除するにはどうすればよいですか？

メニューバーから tTerm を終了し、「アプリケーション」フォルダーからゴミ箱へドラッグします。サインインしていた場合は、Settings → Devices でこの Mac の登録を解除できます。

コードは公開されていますか？

はい。tTerm 全体と同じく、AGPL v3 で公開しています：github.com/tterm-net/tterm-app。
