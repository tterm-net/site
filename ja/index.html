新着：ブラウザーで使える tTerm読む

サーバーとコンピューターの
クラウドターミナル

ターミナルはノートパソコンではなく、クラウドで動いています。ビルドの途中でふたを閉じても、スマートフォンで tTerm を開けば、すべてが離れたときのままです。デバイスに鍵を置く必要も、ポートを開ける必要もありません。

無料で始める オープンソース

Linux サーバー通常の SSH で接続。サーバー側はコマンド 1 つ

macOS と Linux のコンピューターNAT の内側でも、ポートを開けずに

どのブラウザーでもノートパソコン、タブレット、スマートフォンで

使い方

最初のコマンドまで 3 ステップ

01

マシンを追加

サーバーなら、コマンドを 1 つ実行するだけで一覧に加わります。コンピューターには、内側から接続する小さなエージェントを入れます。

$ curl -sSL https://connect.tterm.net/s/… | sudo sh
02

ターミナルを開く

どのブラウザーでも使えます。別々のプロジェクトのタブを横に並べられ、どのマシンにも Cmd+K ですぐ移動できます。

P/web-01A/api-prodP/MacBook
03

いつもどおりに作業

いつものシェル、いつものプログラム、そして sudo。タブを閉じても、ターミナルは動き続けます。

bashzshvimhtopgitdocker

機能

コマンドを理解するターミナル

tTerm は、各コマンドがどこで始まりどこで終わったか、どう終了したか、いまどこにいるかを把握しています。だから出力は、ただ読むだけでなく、そのまま作業に使えるものになります。

~/appmain1.4 s
❯ git pull
Fast-forward
src/server.ts | 12 +++++++-----
1 file changed

コマンドはすべてブロックに

終了コード、時間、ディレクトリ、ブランチ。ブロックは丸ごとコピーでき、折りたたみも再実行もできます。

❯ docker compose logs -f api
→履歴から候補Tab補完

エディターのような入力行

複数行の入力、全デバイスで共通の履歴、候補表示と Tab 補完。危険なコマンドの前には、tTerm がもう一度確認します。

ターミナルに名前を

terminal 2 ではなく、deploy、logs、migrations と名付けられます。ターミナルをダブルクリックし、名前を入力して Enter を押します。

セキュリティ

鍵は預かりません。
ポートも開けません。

マシンへのアクセス権は簡単に付与でき、同じくらい簡単に取り消せます。そのしくみを紹介します。

有効期間 2 分の証明書

接続のたびに、あなたの名前が入った専用の SSH 証明書を発行します。使えるのはそのサーバー 1 台だけです。お使いの鍵は一切必要ありません。

署名を分離

CA の鍵は、ネットワークにつながっていない別のプロセスにあります。コアはこの鍵を読めず、署名を依頼できるだけです。署名はすべて記録されます。

sshd_config はそのまま

信頼の設定は、1 人のユーザーの authorized_keys に書く 1 行だけです。何も再起動しません。

接続は内側から

コンピューターのエージェントは自分から外へ接続するので、受信ポートは必要ありません。アンインストールもコマンド 1 つです。

第三者を介さない

ページもターミナルも、EU にある tTerm のサーバーに直接つながります。Cloudflare は DNS として使っているだけで、コマンドを目にすることはありません。

オープンソース

tTerm Web とエージェントは AGPL のオープンソースです。インストールスクリプトは短いので、実行する前にぜひ読んでください。

よくある質問

自分のコンピューターに何かをインストールする必要はありますか？

いいえ、ブラウザーがあれば十分です。インストールが必要なのは接続先のマシンだけで、サーバーにはコマンドを 1 つ実行し、コンピューターには小さなエージェントを入れます。

どんなデータを保存していますか？

履歴の表示に使うコマンドとその出力（30 日間）、それにサインインの記録です。鍵やパスワードは保存しません。詳しくはプライバシーポリシーをご覧ください。

一般的な SSH クライアントと比べて、何が良いのですか？

どのブラウザーからでも使え、デバイスに鍵を置く必要がありません。ノートパソコンを閉じてもターミナルは切れません。さらに、コマンドはすべてブロックとして表示されるので、コピーも再実行も簡単です。

tTerm のアクセス権を取り消すにはどうすればよいですか？

tTerm でサーバーを削除すると、tTerm は自身のアクセス権をそのサーバーから取り除きます。サーバーが応答しない場合は、サーバー上で同じことを行うためのコマンドを tTerm が表示します。インストーラーが設定したそれ以外のものを削除する方法は、スクリプトの冒頭に書かれています。エージェントは、コマンド 1 つでコンピューターから削除できます。

Telegram ボットはどうなりますか？

今後も残り、引き続き使えます。チャットの中でそのまま使えるターミナル、@tTermNetBot です。今のところ、Web アプリとボットは別々に動いています。

サポートにはどう連絡すればよいですか？

support@tterm.net までメールでご連絡ください。脆弱性を見つけた場合は、security@tterm.net 宛てにお送りください。
