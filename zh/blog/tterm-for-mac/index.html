tTerm Mac 版：内置云端的本地终端

tTerm 推出了 Mac 应用。它以块的形式打开你电脑上的 shell，没有账号也能使用；登录后，你在云端的服务器也会出现在同一个窗口里。免费，支持 macOS 11 或更高版本。

为什么还要做一个应用

tTerm Web 是云终端：服务器的终端都在云端，可以在任意浏览器中打开。但工作常常从自己的电脑开始：构建、git、docker。以前这需要另开一个终端，tTerm 则开在旁边的浏览器标签页里。现在，你的 Mac 和云端都在同一个窗口里。

它能做什么

  • 自己的 Mac 上也有块。 这台 Mac 的 bash 或 zsh，每条命令都是一个块，带有输出、退出码和耗时。输入行支持历史记录和 Tab 补全，遇到危险命令，tTerm 会再确认一次。历史记录在 Mac 上保留 30 天。
  • 无需账号。 这台 Mac 的终端、历史记录和笔记都保存在 Mac 本机上。只有使用云端时才需要账号。
  • 云端就在同一个窗口里。 通过浏览器登录后，你的服务器及其笔记会在 Mac 的终端旁边打开，还可以用 ⌘K 搜索所有内容。
  • 随时随地访问你的 Mac。 应用会把这台 Mac 开放给 tTerm Web：在浏览器和手机上都能使用它的终端。tTerm 常驻在菜单栏中，随 Mac 一起启动。
  • 自动更新。 tTerm 每六小时检查一次有没有新版本，并在不打扰你的时候安装。如果你想自己决定，可以在 Settings → Updates 中设置为安装前先询问你。

安装方法

在下载页面下载 tTerm，打开 tTerm.dmg，把 tTerm 拖到“应用程序”文件夹。应用使用我们自己的证书签名，而不是 Apple Developer ID，所以首次启动时，macOS 会要求你确认，具体方法见下载页面。之后，tTerm 会照常打开，更新时 macOS 也不会再询问。

接下来

很快，应用就能找到这台 Mac 上 ~/.ssh 中的服务器和密钥，点几下就能把它们迁移到云端。之后还会推出 Windows 和 Linux 版。和整个 tTerm 一样，应用的代码也是开源的：github.com/tterm-net/tterm-app，AGPL v3。
