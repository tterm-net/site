迁移到云端：Mac 上的服务器和密钥，在任意浏览器中都能打开

tTerm Mac 版现在可以把你在 Mac 上通过 ssh 连接的服务器，连同你的 SSH 密钥，一起迁移到云端。密钥会存入保险库：它们在你的 Mac 上加密，只有你能打开，在任意浏览器中用保险库密码即可。

为什么要迁移到云端

在 Mac 上，你通过 ssh 连接服务器：密钥在 ~/.ssh 里，地址和用户在 ~/.ssh/config 里。可是一离开 Mac，这些服务器就够不着了：浏览器里不行，手机上不行，别人的电脑上也不行。“迁移到云端”会把它们带进 tTerm，从此在哪里都能打开。

在哪里找到

在 tTerm Mac 版中，点击侧边栏底部的账号，选择“迁移到云端”。窗口会显示“这台 Mac 上的服务器”。tTerm 从 ~/.ssh/config、known_hosts 以及你在它的终端里运行过的 ssh 命令中找出它们。在你点击“迁移”之前，什么都不会离开你的 Mac。

三种连接方式

每台服务器都有自己的连接方式：

  • “我的密钥”： 密钥存入保险库，服务器保持不变。
  • “tTerm 通行证”： tTerm 在服务器上添加一条自己的授权，你的密钥留在 Mac 上。
  • “通过这台 Mac”： 什么都不迁移。Mac 开机期间，tTerm 会请它去连接。适用于位于 VPN 之后的服务器。

tTerm 会自己选好合适的方式，你也可以更改。

密钥保险库

密钥在离开你的 Mac 之前，就已在 Mac 上加密。tTerm 只保存密文、密钥的公钥和它的指纹：我们打不开保险库，也读不了任何密钥。你打开服务器时，由你的设备为登录签名，密钥从不以明文形式离开它。

保险库密码

这个密码由你在创建保险库时自己设定。有了它，你的密钥在任意浏览器中都能打开，即使是在别人的电脑上，身边也没有 Mac。密码本身不会发往任何地方：tTerm 不知道它，也无法找回，所以请把它保存在你的密码管理器中。在你自己的电脑上，点击“用触控 ID 保存”，之后在那里就不会再要求输入密码；在别人的电脑上，请选择“仅此一次”。

只在你打开过密钥的地方

用你的密钥连接的服务器、通过你的 Mac 连接的服务器以及 Mac 本身，只会在你亲自打开过密钥的设备上打开。用邮件里的验证码登录账号，对它们来说还不够：这是第二道锁，以防有人进入你的邮箱。在密钥没有打开的地方，这类机器上会显示一把锁，而不是“+”。点击它，输入密码，终端就会打开。

ssh 之后的提示条

在 tTerm Mac 版的终端中，ssh 无错误结束后，它的块下方可能会出现一个提示条，上面有“保存我的密钥”和“允许 tTerm 登录”。这样不用打开迁移窗口，也能单独迁移一台服务器。

以上功能都在 tTerm Mac 版 0.8.1 中。详情见文档中的“迁移到云端”和“你的 SSH 密钥保险库”页面。
