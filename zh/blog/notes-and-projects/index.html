笔记、彩色项目和终端名称

运维手册、检查清单和访问说明，现在就放在相关机器的旁边。你可以创建自己的项目并为每个项目设定颜色，给终端命名，还能把机器和笔记从一个项目移到另一个项目。以下是 tTerm Web 上线头几天新增的功能。

笔记就在机器旁边

笔记放在项目的文件夹里，就像终端运行在项目的机器上一样：部署手册、发布检查清单、访问密钥的存放位置。笔记会在终端旁边的标签页中打开，照着手册操作时，它始终在你眼前。

边输入边生效的 Markdown

行首的 # 生成标题，- [ ] 生成检查项，三个反引号生成代码块，/ 则打开包含所有这些格式的菜单。代码块带有 Copy 按钮。检查清单会显示每一项由谁在什么时候勾选，整篇笔记可以复制为 Markdown。

两台设备同时编辑

笔记在你输入时自动保存。在两台设备上同时编辑时，两边的修改都会保留，只有两边都改过的地方 tTerm 才会询问你。如果连接中断，你输入的内容会暂存在浏览器里，下次打开这篇笔记时恢复。

自己的项目

除了 Personal，现在你还可以创建自己的项目：每个客户、每个环境或每项工作一个。每个项目都有自己的机器、终端和笔记。任何项目都可以重命名，Personal 也可以，还可以修改项目代号，也就是标签页上的前缀，例如 CX/web-01。没有机器的项目可以删除，其中的笔记会一并删除。

机器可以移到另一个项目，其中的终端会继续运行，机器本身不会有任何变化。笔记也可以移到另一个项目，放进它的任意文件夹。

彩色项目

每个项目都有八种颜色中的一种。这个颜色会填充侧边栏和标签页中的项目代号，所以一眼就能看出标签页属于哪个项目。在账号页面上，你可以选择颜色只用于代号，还是用于侧边栏中的整个项目区块。

终端名称

终端不必再叫 terminal 2：可以叫 deploy、logs 或 migrations。在标签页、侧边栏或项目页面上双击终端，输入名称，按 Enter。终端出现在哪里，名称就显示在哪里。

新的侧边栏和项目页面

在侧边栏中，每个项目下是它的机器及其终端，以及按文件夹整理的笔记。点击机器或文件夹只会将其折叠，旁边的加号用于打开终端或新建笔记，点击项目名称则会打开项目页面：所有机器及其打开的终端，以及所有笔记。

接下来

下一个重点是团队协作：项目成员、角色、共享的命令日志，以及旁观同事的终端，被旁观的人始终能看到谁在看。届时，笔记也会由项目中的所有人共享。

与此同时，我们正在开发电脑版 tTerm：同样的界面，放在独立的窗口里，用于你电脑上的 shell。
