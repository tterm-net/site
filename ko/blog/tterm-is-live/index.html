tTerm 출시

서버를 위한 터미널을 바로 이곳 Telegram에서 쓸 수 있어요. 명령을 입력하면 내 머신에서 실행되고, 종료 코드, 작업 디렉터리, git 브랜치가 담긴 메시지로 결과가 돌아와요. 셸은 마지막으로 작업하던 위치를 기억해요.

지금 할 수 있는 것

  • SSH로 연결하는 Linux 서버: 명령 한 줄로 연결, sshd_config 수정 없음
  • 포트를 열지 않는 작은 에이전트로 연결하는 macOS와 Linux 컴퓨터
  • 어떤 Telegram 사용자에게든 접근 권한 공유: 정해진 기간 동안, 또는 회수할 때까지
  • 공유받은 사람이 실행한 모든 명령은 그 사람의 이름과 함께 내 로그에 남아요

무료, 오픈 소스, 가입 필요 없음.

베타 버전이에요. 잘 작동하지만 앞으로도 계속 바뀔 거고, 바뀌는 내용은 이 채널에서 알려 드려요.
