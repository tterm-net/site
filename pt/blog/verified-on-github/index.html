O tTerm agora é uma organização verificada no GitHub

O github.com/tterm-net tem o selo Verified: o GitHub confirmou que por trás da organização e do tterm.net estão as mesmas pessoas.

Aqui isso importa mais do que importaria em outros lugares. O código é aberto, então qualquer pessoa pode fazer um fork, mudar o comando de instalação e publicar com um nome parecido com o nosso. Mas não dá para fazer fork de um domínio. O selo liga os dois, e assim existe um lugar que comprovadamente somos nós:

  • github.com/tterm-net: os três repositórios, verificados
  • tterm.net: o site
  • @tTermNetBot: o próprio bot
