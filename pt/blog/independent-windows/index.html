As janelas no computador agora são independentes

Num servidor, cada janela sempre foi um terminal à parte. Num computador com o agente, todas as janelas compartilhavam um único shell: um cd em uma delas movia as outras também, e, enquanto um programa rodava numa janela, as demais tinham que esperar. Agora cada janela tem o seu próprio shell, como num servidor. Você pode deixar um servidor de desenvolvimento rodando numa janela e trabalhar em outra.

Para ter isso, atualize o agente: /addhost → Computer, e rode no mesmo computador o comando que aparecer. A máquina continua na sua lista como está. Se o seu agente for antigo, o bot avisa quando você abrir uma segunda janela.

O que mais mudou

  • Os botões das janelas ficam no fim da lista e valem para a linha selecionada, então não pulam mais de lugar quando você troca de janela
  • Se você muda para uma janela em que um comando está rodando, o bot avisa na hora, em vez de esperar o comando terminar
  • Um computador não aparece mais como offline depois que o agente se reconecta rapidamente
