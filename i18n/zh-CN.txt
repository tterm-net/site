# security
index.security.1 = 安全
index.security.2 = 我们不保存密钥，<br>也不开放端口。
index.security.3 = 机器的访问权限很容易授予，也同样容易收回。具体做法如下。
index.security.4 = 两分钟有效的证书
index.security.5 = 每次连接都会获得一张单独的 SSH 证书，里面写着你的名字，只对这一台服务器有效。我们从不需要你的密钥。
index.security.6 = 签名独立进行
index.security.7 = CA 密钥存放在一个不联网的独立进程中。核心程序无法读取它们，只能请求签名，每次签名都会记录在案。
index.security.8 = 不改动 sshd_config
index.security.9 = 信任关系只是某个用户 authorized_keys 中的一行。不需要重启任何东西。
index.security.10 = 由内向外连接
index.security.11 = 电脑上的代理会主动向外连接，因此不需要任何入站端口。卸载只需一条命令。
index.security.12 = 没有中间人
index.security.13 = 页面和终端直接连到我们位于欧盟的服务器。Cloudflare 只为我们提供 DNS，看不到你的命令。
index.security.14 = tTerm Web 和代理以 AGPL 许可证开源。安装脚本很短：运行之前先读一读。

# faq
index.faq.1 = 常见问题
index.faq.2 = 我需要在自己的电脑上安装什么吗？
index.faq.3 = 不需要，有浏览器就够了。只有要连接的机器才需要装东西：服务器上运行一条命令，电脑上装一个小型代理。
index.faq.4 = 你们会保存哪些数据？
index.faq.5 = 命令及其输出保存 30 天，用于显示你的历史记录，另外还有登录日志。我们不保存密钥，也不保存密码。详情见<a href="/privacy/">隐私政策</a>。
index.faq.6 = 它比普通的 SSH 客户端好在哪里？
index.faq.7 = 它在任何浏览器中都能用，设备上不需要密钥。合上笔记本，终端也不会断开。而且每条命令都是一个块，复制和重新运行都很方便。
index.faq.8 = 怎样收回 tTerm 的访问权限？
index.faq.9 = 在 tTerm 中删除服务器，它会自行撤销在这台服务器上的访问权限。如果服务器没有响应，tTerm 会显示在服务器上完成这一步的命令。安装程序设置的其他内容如何清除，写在脚本本身的开头。代理只需一条命令就能从电脑上卸载。
index.faq.10 = Telegram 机器人还在吗？
index.faq.11 = 它会保留并继续运行：聊天里的终端，<a href="https://t.me/tTermNetBot" target="_blank" rel="noopener">@tTermNetBot</a>。目前网页版和机器人是分开的。
index.faq.12 = 怎样联系技术支持？
index.faq.13 = 写信到 <a href="mailto:support@tterm.net">support@tterm.net</a>。如果你发现了漏洞，请写信到 <a href="mailto:security@tterm.net">security@tterm.net</a>。

post.open-source.prose.4 = tTerm 会连接到你的机器。在服务器上，它以带 sudo 权限的 tterm 用户登录，也就是拥有 root 权限。对于拥有这种访问权限的服务，不能光凭它自己的说法就信任它，所以与此相关的一切都是开源的：核心程序、负责签发证书的独立程序、安装程序和代理。
